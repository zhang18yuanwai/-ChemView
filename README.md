# ChemView · 微观化学实验室

高中化学互动示意站（开源、免费、纯静态页面）。

🌐 在线访问：https://zhang18yuanwai.github.io/-ChemView/

> 课堂示意，非精确仿真。

## 现在有什么

- 原电池工作原理微观实验（单液 / 双液、盐桥、电子与离子迁移）
- 可切换电极、电解质、外电路负载
- 方程式与传感器示意曲线

## 本地打开

用浏览器直接打开仓库里的 `index.html` 即可，无需安装。

## 怎么更新网站

1. 在本地修改 `index.html` 并先自己预览
2. 上传覆盖到本仓库**根目录**的 `index.html`
3. 打开 Actions，等待 `pages build and deployment` 变绿
4. 刷新网站（可 Ctrl+F5）

**GitHub Pages 设置（重要）**

- Source：Deploy from a branch  
- Branch：`main`  
- Folder：`/ (root)`（不要选不存在的 `/docs`）
